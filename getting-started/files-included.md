# Files included

When you purchase our theme from ThemeForest, you need to download the theme package from your ThemeForest account. Navigate to your **Downloads** tab on ThemeForest and find **Pipsy**. Click the download button to see the two options. **All files & documentation** contains everything, **Installable WordPress file only** is just the installable WordPress theme file. Below is a list of what is included when you download the main files.

The download is named `Pipsy_v1.0.0.zip`. Unzip it on your computer first; it contains four folders:

* `Theme Files`
  * `pipsy.zip` – the main theme file that you upload to install the **Pipsy** theme.
  * `pipsy-child.zip` – a ready-made child theme. See [Child Theme & Custom Code](../customization/child-theme-and-custom-code.md).
* `Plugins` – the companion plugins of this theme:
  * `kitify.zip` – Kitify, the Elementor extension used for headers, footers, shop, product and blog templates.
  * `pipsy-core.zip` – Pipsy Core: Theme Options, the Pipsy Elementor widgets, mega menu, product story fields and the products filter.
  * `pipsy-demo-data.zip` – Pipsy Package Demo Data: the one-click demo importer.
* `Documentation` – `online_document.txt`, with the link to this documentation.
* `Licensing` – `GPL.txt` and `README_License.txt`, the license files of the theme and its plugins.

{% hint style="info" %}
You don't have to upload the plugins by hand. After you activate the theme, **Appearance > Install Plugins** downloads and installs them for you. See [Step 3 - Install Plugins](../installation/step-3-install-plugins.md).
{% endhint %}
