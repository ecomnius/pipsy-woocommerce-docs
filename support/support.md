# Support & Credits

Thank you for purchasing **Pipsy**. If this documentation doesn't answer your question, our support team is happy to help.

## How to get support

Open a ticket at our help center: [support.ecomnius.com](https://support.ecomnius.com/).

To help us answer faster, please include:

* Your ThemeForest **purchase code** ([where to find it](https://help.market.envato.com/hc/en-us/articles/202822600-Where-Is-My-Purchase-Code-)).
* The URL of your site and a short description of the problem, with screenshots if possible.
* The versions of WordPress, WooCommerce, Elementor, Kitify, Pipsy Core and Pipsy you are running (**Tools > Site Health > Info**).

We answer tickets Monday to Friday, usually within 24–48 hours.

## What support covers

Item support, as defined by [Envato's item support policy](https://themeforest.net/page/item_support_policy), includes:

* Answering questions about how to use the theme and its bundled plugins.
* Answering technical questions about the theme's features.
* Fixing bugs and reported issues in the theme.
* Providing updates so the theme keeps working with new versions of WordPress, WooCommerce and Elementor.

Support does **not** include custom design or development work, installation or configuration of third-party plugins that aren't bundled with the theme, or problems caused by changes to the theme's code.

## Before you open a ticket

Many problems are solved by these quick checks:

1. Read [FAQ & Troubleshooting](faq-and-troubleshooting.md).
2. Make sure you meet the [requirements](../getting-started/requirements-for-pipsy.md) (WordPress 6.5+, PHP 7.4+).
3. Update the theme and its plugins to the latest versions. See [Updating Pipsy](updating-pipsy.md).
4. Deactivate plugins that aren't required by Pipsy, then check whether the problem is still there.
5. Clear any caching plugin, server cache or CDN cache, then reload the page.
